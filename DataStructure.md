1. What are the 4 main built-in data structures in Python?
lists, dictionaries, tuples, and sets

2. What does it mean for data to be mutable? Immutable?
Mutable data can be changed after it is created, while immutable data cannot be changed. 

3. What is the difference between a list and a tuple?
A list and a tuple differ mainly in their mutability, syntax, and use cases.

4. Pick one of the mutable data structures. How do you add an item to that data structure? 
A list is a primary example of a mutable data structure. In Python, you can add an item to a list in a few different ways depending on where you want the new item to go

5. How do you access an item in a list or tuple?
To access an item in a list or tuple, you use square bracket notation [] with the item's index number

6. What characters are used to create a list, tuple, dictionary &, tuple respectively?
The characters used to create a list, tuple, and dictionary respectively are square brackets [], parentheses (), and curly brackets {}. (Note: the prompt repeated "tuple" at the end, which uses parentheses ()).
