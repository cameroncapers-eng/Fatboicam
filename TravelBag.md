1. What is one difference between a list and a tuple?
One main difference between a list and a tuple is that a list is mutable, while a tuple is immutable.

2. When is it better to use a list over a tuple?
It is better to use a list over a tuple when your collection requires mutability, dynamic resizing, or homogeneous data processing.

3. How do you remove an item from a list?
You can remove an item from a Python list using the remove() method, the pop() method, or the del keyword.

4. Name at least 2 mutation functions you can use on lists.
Two common mutation functions (methods) used on lists in Python are append() and remove(). These methods change the original list in place rather than creating a new list.
