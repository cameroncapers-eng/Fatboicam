1. An if-statement works by checking a specific condition and running a designated block of code only if that condition evaluates to true

2. to allow a program to make decisions.

3. An else statement works as a backup plan in computer programming. It follows an if statement, running its own block of code only if the main if condition is false.

4. elif (short for "else if") allows you to check multiple conditions in a specific sequence. When used in an if statement, it only evaluates its condition if all previous if and elif conditions were False. As soon as one evaluates to True, its block of code runs and the rest of the chain is skipped.
